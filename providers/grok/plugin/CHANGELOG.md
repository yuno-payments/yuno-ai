# Changelog

All notable changes to this plugin are documented here.

## 0.1.0 — unreleased

- Initial plugin: the `yuno` MCP server at `https://mcp-edge.agents.y.uno/mcp`,
  authenticated with OAuth 2.1 (Dynamic Client Registration, PKCE `S256`). No
  variables to configure.
- Skills: `yuno-auth-and-environments`, `yuno-payment-flows`, `yuno-webhooks`,
  `yuno-sdk-setup`, `yuno-errors-and-testing`.
- Commands: `/explain-error`, `/test-cards`.
- Logo: Yuno's official isotype (`YUNO_ISO_BLUE_1`), supplied by Yuno — 1:1 SVG on
  the brand background plate.
